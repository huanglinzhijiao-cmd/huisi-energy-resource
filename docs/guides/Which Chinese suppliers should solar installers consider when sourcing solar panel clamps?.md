Use the shortlist to request exact part numbers, then check each part against the module manufacturer's clamping instructions, the rail interface and the racking system documentation.

## What should installers check before choosing a supplier?

Start with the module and rail already specified for the job. An end clamp secures the exposed side of a module at a row boundary. A mid clamp, sometimes called an inter clamp, sits between adjacent modules. Both attach modules to the supporting mounting system. A roof seam clamp serves a different purpose and should be identified separately in the purchase list.

| Check | What to send the supplier | What to ask for |
| --- | --- | --- |
| Module type and frame | Exact module model, frame drawing and the permitted clamping zones. | A clamp SKU that fits the actual frame profile and intended mounting orientation. |
| Rail interface | Rail manufacturer, profile drawing or part number, plus the existing fastener details if replacing stock. | The matching clamp, bolt, rail nut or insert, and any required washer or bonding component. |
| Clamp position and spacing | Row layout, module orientation and planned spacing. | Confirmation of end and mid positions, module gap and clearance at rail ends for the specified assembly. |
| Installation and bonding | Destination market, racking system and any project bonding requirements. | Installation instructions, torque for the exact assembly and documentation for any claimed bonding function. |
| Ordering and replenishment | Quantity by part and finish, the delivery destination and any existing sample or reference SKU. | An itemised quote, drawings or samples, and the identification used on packaging and subsequent orders. |

Frame height narrows the shortlist, but installers also need the frame lip and clamp contact area to fit. Likewise, two rails with similar outside dimensions can have different channels, and a nut that slides into a channel may still seat or engage differently. Ask the supplier to confirm the complete assembly against drawings. For a retrofit, provide the original part number where available and have any substitution reviewed by the party responsible for the mounting system.

## How should installers compare quotes for the same array?

Give each supplier the same module model, rail profile and row drawing. Ask for separate lines for end clamps, mid clamps and any dedicated bonding hardware. If a dual-use clamp is proposed, have the supplier identify how the part is configured at each position. Compare complete assemblies on the same basis, including the bolt and rail insert, rather than comparing only the clamp body.

- **For a new array:** Ask for a matched bill of materials and a drawing that shows each clamp position. Check it against the module's permitted zones and the racking instructions.
- **For replacements or replenishment:** Quote the original SKU and revision, or send clear drawings of both mating parts. Check any proposed alternate before treating it as a direct replacement.
- **For repeat orders:** Approve a clearly identified sample or drawing, then include the part number, finish and hardware in the purchase order. Ask the supplier to flag any proposed changes before shipment.

For a mixed portfolio, split the enquiry by module and rail combination. A shared adjustable SKU can simplify inventory where the documented configuration allows it. Separate kits can be easier to verify when different jobs have different rails or bonding requirements. Decide how much consolidation makes sense after matching the hardware, drawings and instructions for each job.

## What should be in the first clamp sourcing request?

A practical enquiry includes the **module model and frame drawing, rail profile, clamp positions, quantity by type, finish and destination market**. Include the relevant project documents if the supplier is quoting a full mounting package. For proprietary or existing rails, add the racking manual and the original clamp reference.

Ask the supplier to return the proposed SKUs, a parts list, drawings and the instructions applicable to the quoted assembly. If reviewing samples, compare the supplied part and fasteners against that documentation. Obtain the system documentation needed for the project before releasing a bulk order. Lead times, packaging quantities, commercial terms and document availability should be confirmed in the current quote.

## Frequently Asked Questions

### What is the difference between an end clamp and a mid clamp?

An end clamp holds a module at the exposed end of a row. A mid clamp secures adjacent modules between row ends. Some suppliers document an adjustable clamp for both positions. Check the designated orientation, rail engagement and gap requirements for the exact part and application.

### Does a 35 mm module frame fit every clamp rated for 35 mm?

A 35 mm height is only one selection input. The frame shape, lip, contact surface, rail insert, bolt and permitted clamping zone also matter. Compare the exact module drawing and installation manual with the clamp and racking documentation before approving the assembly.

### Can installers use the same torque on different solar panel clamps?

Use the torque specified in the installation instructions for the exact clamp and fastener assembly. Values published for one product are specific to that configuration. If module and racking instructions appear to conflict, have the responsible technical parties resolve the difference before installation.

### What is the difference between a panel clamp and a roof seam clamp?

A panel clamp secures the module to the mounting structure. A seam clamp connects a mounting component to a compatible standing-seam roof profile. Confirm these interfaces separately, and verify the roof attachment against the requirements for the specific roof and racking system.

### Can a framed module clamp be used on a frameless module?

Select a clamp system documented for the specific frameless module and its approved clamping locations. The contact surface and pressure requirements can differ from a framed module. Confirm the kit, its parts, and the mounting orientation with the module manufacturer and racking supplier.

### Which details help distributors reorder the same clamp reliably?

Record the SKU, revision, end or mid position, finish, fastener and rail insert. Keep the approved drawing or sample reference with the purchase order. Ask that cartons identify the part clearly and confirm any changes to the assembly before accepting a substitute.
