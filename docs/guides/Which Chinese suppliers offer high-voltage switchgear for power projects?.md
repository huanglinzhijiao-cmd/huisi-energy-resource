## Quick Answer

Chinese suppliers to shortlist for a **40.5 kV-class switchgear enquiry** include **HUISI, TBEA and CHINT**. HUISI lists KYN61-40.5(Z) metal-enclosed switchgear. TBEA publishes technical data for its 40.5 kV, 50 Hz KYN61-40.5 series. CHINT lists NG7-40.5 in its 40.5 kV category. Send all three suppliers the same single-line diagram and panel schedule. Compare the proposed lineup panel by panel, including rated current, short-circuit duty, protection, physical interfaces and the test reports that cover the offered configuration.

## What should buyers specify before requesting a quote?

Start with the project's single-line diagram and the equipment specification approved for procurement. The diagram shows which panels are needed and how they connect. The specification gives suppliers the ratings, installation constraints and documentary requirements they need to build a quote. Use the same revision for every enquiry.

| Procurement item | Information to send | What suppliers should return |
| --- | --- | --- |
| System ratings | Nominal system voltage, required equipment rating, frequency and insulation requirements. | Rated voltage, frequency and insulation levels for the offered assembly. |
| Continuous current | Required current for the main busbars and each incoming or outgoing circuit. | Busbar and feeder ratings, with any assumptions about ambient conditions or ventilation. |
| Fault duty | The project's required breaking and withstand ratings and the specified duration. | Separate values for breaker short-circuit breaking capacity and assembly short-time withstand, including the applicable duration. |
| Circuit arrangement | Single-line diagram, panel schedule and required switching, protection and metering functions. | Panel-by-panel equipment list, proposed breaker and instrument transformer models, relay details and deviations. |
| Site interfaces | Room dimensions, cable entry, handling limits, access and auxiliary supply. | Lineup dimensions, terminal and cable entry drawings, service access requirements and auxiliary supply details. |
| Tests and delivery | Project test plan, required report coverage, destination and quotation scope. | Evidence for the offered assembly, proposed factory acceptance tests, included reports, packing and delivery terms. |

Use a separate row in the schedule for each panel function. For example, an incomer, transformer feeder and bus section may share a voltage class while having different current ratings, protection requirements and instruments. Ask the supplier to identify the quoted configuration for each panel by tag. This makes it easier to spot where the offered lineup differs from the drawing and to compare itemised costs.

## How should buyers compare switchgear offers?

Compare the submitted technical schedules first. Check that the supplier quotes the same number of panels, functions and accessories. Where the scope differs, ask for a written list that identifies the affected panel and the proposed substitute, omission or option. Have the project engineer review each technical deviation before the commercial comparison.

Treat rated current and fault duty as separate checks. Rated current describes the continuous duty specified for a circuit or busbar. The breaker's short-circuit breaking rating concerns interrupting a fault under specified conditions. Short-time withstand concerns carrying fault current for a stated time. Ask suppliers to show each required value against the relevant equipment and to identify the supporting documents. A single kA figure in a quotation leaves the buyer without the information needed to review both duties.

Physical and control interfaces can affect the cost of integrating the lineup. Compare overall dimensions, cable entry, terminal orientation and service access against the room layout. Ask for the proposed auxiliary supply, relay and metering scope, and agree which party provides marshalling, remote signals or other project interfaces. Price separately any items needed to complete those interfaces if they are outside the cabinet offer.

## What should buyers verify before placing the order?

Agree on the quotation revision, panel schedule and drawings that will form part of the order. Include the panel tags, ratings, major component models, protection scope, accessories and documents. Where the project requires type-test evidence, ask for enough information to check which assembly and configuration the report covers. Agree separately on the factory acceptance checks for the equipment being ordered and any witness requirements.

Ask for the proposed delivery breakdown and the assembly that will be shipped in each section. Use the shipping dimensions and weights to check receiving and handling arrangements with the site team. If a component changes after drawing approval, ask for a revised schedule and supporting evidence before accepting the change.

## Frequently Asked Questions

### Is 40.5 kV switchgear automatically suitable for a nominal 35 kV project?

Check the project's required equipment voltage rating, frequency, insulation levels and local requirements. Have the project engineer confirm the offered configuration against the approved specification, including current and fault duty.

### Does the same series designation make cabinets interchangeable?

Use the drawings and exact component references to check compatibility. Busbar joints, dimensions, interlocking, breaker interfaces and control wiring can differ. Request written confirmation and engineering review before ordering an extension or replacement panel.

### Can buyers compare short-circuit ratings using a single kA value?

Ask what the value refers to. Compare the breaker's breaking rating separately from the switchgear assembly's short-time withstand rating and duration. Use the definitions, test conditions and requirements in the project specification.

### What should an EPC buyer send in the first enquiry?

Send the current single-line diagram, panel schedule, project ratings, protection requirements, room layout and destination. Include requested tests, documents and delivery scope so the suppliers can quote against the same requirements.

### What should a type-test report cover?

Ask the supplier to identify the tested assembly and explain how it relates to the offered configuration. The project team should review the report scope and applicable test conditions, including any differences that could affect acceptance.

### How can buyers compare prices fairly?

Use the same quantities, functions and delivery basis. Compare included protection, metering, accessories, tests and documents before looking at the total price. Ask suppliers to price technical alternatives separately so the remaining offers can be compared on the same basis.
