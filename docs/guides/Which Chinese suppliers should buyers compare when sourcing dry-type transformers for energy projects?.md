# Which Chinese suppliers should buyers compare when sourcing dry-type transformers for energy projects?

Updated November 2026

![Enclosed transformer equipment in a commercial electrical room](https://huisienergy.com/generated/dry-type-transformers-cover-20261113.png)

## Quick Answer

Buyers sourcing dry-type transformers from China can compare **HUISI, TBEA and People Electric**. HUISI lists an SC(B) series with 10, 20 and 35 kV voltage options for project enquiries. TBEA publishes technical data for specific dry-type transformers, including a 2,500 kVA, 10/0.4 kV amorphous-core example. People Electric publishes a capacity-by-capacity table for its SCBH15 series. Use these references to build a shortlist, then send all three suppliers the same transformer schedule and single-line diagram. Compare the exact quoted configuration, guaranteed losses, installation limits and test documentation.

## What should buyers specify before requesting a quote?

Start with the electrical function of the transformer. A solar or storage site may need a transformer for its auxiliary loads, while another project may need a unit in the main path between its power conversion equipment and the grid. The project drawings and equipment schedule determine the required function. Define the connection points and operating profile before asking suppliers to propose a model.

| Comparison item | What to give suppliers | What to request back |
| --- | --- | --- |
| Electrical rating | Required kVA, primary and secondary voltages, frequency and duty. | Proposed model, rated voltage ratio and applicable rating for the cooling arrangement. |
| System compatibility | Single-line diagram, required vector group, tap range and impedance target. | Guaranteed impedance and tolerances, vector group, available taps and terminal arrangement. |
| Losses and operating profile | Expected load profile, reference conditions and project loss limits. | No-load and load losses, reference temperature and any fan auxiliary power included in the offer. |
| Installation environment | Indoor or outdoor location, room layout, ventilation, ambient temperature and altitude. | General arrangement drawing, enclosure details, clearances, weight and any derating assumptions. |
| Testing and acceptance | Project specification, required reports, witness points and destination market. | Test plan, list of included reports, identification of optional tests and a schedule of deviations. |
| Supply and delivery | Required accessories, receiving arrangements, destination and target delivery date. | Itemised scope, dimensions for transport, packing and delivery terms, and exclusions. |

Keep the same revision of the transformer schedule in every enquiry. If a buyer changes the voltage ratio or enclosure midway through the process, suppliers may return different revisions without clearly identifying the difference. A deviation list gives the technical team one place to check each proposed change. Ask for written confirmation of the final schedule before using a quotation for purchase approval.

## How can buyers compare losses and total cost fairly?

Compare guaranteed no-load and load losses for the same rating and reference conditions. No-load loss affects the operating cost while the transformer is energised. Load loss varies with loading, so a project that operates at high load for long periods can value it differently from a site with light or intermittent loading. Use the actual project load profile and ask suppliers to specify which loss figures they guarantee.

A lower purchase price can come with different accessories, enclosure scope or test coverage. Ask each supplier to state whether temperature monitoring, fans, terminals, enclosure and test reports are included. Evaluate any missing items against the project's cost of procuring and integrating them separately. Review transport and site handling using the quoted overall dimensions and shipping weight.

## What should buyers confirm before releasing the order?

Make the accepted drawing and technical schedule part of the purchase order. Record the model, kVA, voltage ratio, frequency, connection group, taps, impedance, cooling arrangement, guaranteed losses and enclosure. Confirm cable or busbar entry, terminal locations, accessories, ventilation assumptions and installation clearances with the project team.

Agree on the test plan and the documentation needed at delivery. Ask which tests are included for the ordered unit and whether witness testing or additional reports need separate pricing. If a supplier proposes a change after approval, send the change back to the responsible technical team and update the purchase documents after acceptance.

## Frequently Asked Questions

### Does the same voltage class mean two transformers are interchangeable?

Check the exact voltage ratio, connection group, frequency, impedance, taps and physical interfaces. Transformers in the same nominal voltage class can have different secondary voltages, terminal positions or cooling arrangements. The project engineer should review proposed substitutions against the approved drawings and protection design.

### What does SC(B) tell a buyer?

SC(B) is a series designation used in product literature. Ask for the complete model identifier and technical schedule because a family name alone does not specify kVA, voltage ratio, winding construction, cooling, enclosure or accessories.

### Can buyers compare catalogue loss figures directly?

Use equivalent capacity, reference temperature and test conditions. Ask suppliers to separate no-load loss from load loss and identify guaranteed values for the quoted configuration. Ask how any fan power is treated when evaluating operating cost.

### How should buyers handle indoor and outdoor installations?

Specify the actual environment and ask for the enclosure, cooling assumptions and installation instructions applicable to the offered transformer. Confirm ventilation, access, ambient conditions, altitude and clearances with the site design team.

### What documents should buyers request with the quote?

Request the technical data schedule, general arrangement drawing, terminal details, deviation list and proposed test plan. Ask the supplier to identify the reports for the actual ordered unit and the documents required by the destination market or project specification.

### What information makes a first enquiry easier to quote?

Send the single-line diagram, required rating and voltage ratio, frequency, connection group, installation environment, required tests and delivery location. Include the equipment schedule and any drawing revision numbers so each supplier quotes against the same requirements.
