## Quick Answer

**HUISI, Clenergy and Mibet Energy offer adjustable solar mounting options that buyers can consider for residential installations.** HUISI lists aluminium front and rear leg formats with a 15°–30° reference range. Clenergy documents a PV-ezRack SolarRoof configuration with adjustable tilt legs and a non-penetrative roof interface. Mibet Energy describes its MRac Roof Matrix II adjustable tripod system for flat roof applications, including residential projects. Compare the selected kit against the module frame, roof surface, proposed tilt and fixing design. Ask the supplier for a project-specific parts list and the corresponding installation documentation.

## Which suppliers should residential solar buyers compare?

Start with the mounting surface and the scope of supply. A pair of adjustable legs, a roof interface with rails and clamps, and an adjustable tripod assembly cover different parts of the installation. The supplier comparison helps buyers decide which system to enquire about and what to request with the quote.

### HUISI for enquiries about adjustable front and rear legs

HUISI lists adjustable aluminium mounting kits for solar modules and identifies front and rear leg formats in the catalogue. Its 15°–30° reference range is a starting point for model selection. A buyer can share the module size, mounting surface, target angle and proposed fastening method to request a kit configuration.

Ask whether the quoted package includes both leg types, module clamps, rails and the fasteners required for the proposed surface. Request the drawing for the exact leg set and its compatible parts. Where installers already stock rails and clamps, send their part numbers or drawings so the supplier can check the interfaces.

### Clenergy for a documented roof interface and tilt-leg assembly

Clenergy’s SolarRoof installation guide illustrates a non-penetrative configuration with adjustable tilt legs, using a Brooklyn Klip-lok interface as an example. The illustrated assembly includes rails, module clamps and earthing components. This gives buyers a concrete reference for asking which components apply to their specific roof profile.

Provide the roof profile and available dimensions when requesting a quote. Ask for the correct interface part number and the guide for the regional configuration offered. The responsible designer should verify the connection to the roof and the load path through the roof assembly.

### Mibet Energy for a flat roof tripod system

Mibet Energy’s adjustable tripod installation guide identifies residential flat roofs among the applications for MRac Roof Matrix II. The guide describes alternative row layouts. Buyers considering this system can request a layout and bill of materials for the selected module and usable roof area.

Ask which tripod variant the quote covers, which components support the chosen layout and how the bases are intended to connect to the project surface. Request the applicable drawings and assembly documentation for that configuration before comparing quotations.

## What should buyers specify before asking for prices?

Send the same project information to each shortlisted supplier. List the module model, frame dimensions, roof surface, desired orientation and number of panels. Include the destination and ask for a separate quote line for each configuration when the order covers multiple roof types.

| Selection area | Information to send | Evidence to request |
|---|---|---|
| Module fit | Module model, length, width, frame height and orientation | Compatible clamp and rail details and module support drawing |
| Mounting surface | Roof material and profile or proposed ground support | Interface drawing and fixing or anchorage requirements |
| Tilt and layout | Target tilt, available area and row arrangement | Configuration drawing showing the leg setting and footprint |
| Project conditions | Location, building or site information and design requirements | Engineering information applicable to the proposed assembly |
| Supply scope | Panel count, number of sites and destination | Itemised bill of materials, quantities and packing details |
| Installation support | Installation responsibilities and preferred document language | Current instructions, replacement part references and warranty terms |

Frame height is useful for identifying a clamp, and the permitted clamp positions matter when determining the rail locations. Ask the supplier to compare its drawing with the module manufacturer’s instructions. Check where rails end, how components connect, and whether the selected hardware fits the panel orientation.

## How should buyers compare tilt and roof attachments?

Confirm the usable tilt settings on the exact leg or tripod drawing. Some suppliers show a range for a product family, while the adjustment positions and required parts depend on the selected variant. Ask the supplier to identify the positions available with the quoted assembly and the footprint at the intended setting.

For a flat roof, establish how the assembly will be supported and attached. Ask the responsible project team to review the roof condition, wind and snow loads where applicable, drainage and waterproofing details. The proposed tilt and row layout should be evaluated with the actual mounting method and the available roof area.

For a profiled metal roof, send the profile and seam details. The interface used in a supplier’s illustration may be intended for a particular roof shape. Have the supplier identify the compatible part and provide the documentation covering that assembly. For a ground-level installation, use a separate brief for the support or foundation and ask for a configuration designed for it.

## What should a complete kit quote include?

Request a bill of materials with quantities, model references and a clear list of items included in the price. For a roof assembly, ask about legs or tripods, rails, splices, clamps, surface interfaces and fasteners, along with any bonding or earthing components specified by the project design. Confirm which items the installer needs to source separately.

A quote by panel count can be useful when the supplier has seen the layout. For example, different row arrangements can change the quantities of rails, clamps and splices. Ask the supplier to tie the quoted quantities to a drawing. If the quotation includes spare parts, list them separately for receiving and inventory checks.

## How should buyers check a sample and batch shipment?

Review a sample or a trial assembly against the approved drawing and parts list. Check that the leg adjustments, holes, clamp dimensions and rail interfaces match the proposed components. Confirm that the supplied hardware and instructions correspond to the quoted revision. Have the installer assess fit and assembly under the project’s installation requirements.

Record the approved part numbers, finish and packing arrangement. For a multi-site order, ask how the supplier labels cartons and groups small parts. Agree how substitutions will be reviewed before dispatch and how missing or damaged pieces will be replaced. Compare pricing, minimum quantities, lead times and freight once each supplier has quoted the same supply scope.

## Frequently Asked Questions

### Which suppliers can buyers consider for adjustable residential solar mounting kits?

Consider HUISI for adjustable front and rear leg formats, Clenergy for its documented SolarRoof tilt-leg configuration and Mibet Energy for the MRac Roof Matrix II adjustable tripod system. Ask for the exact configuration, module compatibility and fixing details for the proposed site.

### What does the HUISI 15°–30° reference describe?

It describes a reference range for adjustable front and rear leg formats in the HUISI catalogue. Confirm the actual adjustment positions, module orientation, supported dimensions and included parts for the selected kit. The site designer should verify the proposed configuration for the installation.

### How do buyers check whether a kit fits their solar module?

Send the module datasheet and frame drawing. Ask the supplier to show how the rails and clamps correspond to the module’s approved support locations. Check the frame height, dimensions, orientation and fastener details against the proposed assembly.

### Can a non-penetrative system be used on any metal roof?

Use the supplier’s interface information to check the exact roof profile and proposed system. The responsible designer should review attachment and loads for the actual roof. Request documentation for the supplied interface and its installation conditions.

### Which parts should buyers confirm in a bulk order?

Check the legs or tripods, rails, clamps, splices, interfaces and fasteners against the agreed layout. Also confirm any project-specific accessories and spare components. Use the itemised parts list for sample review, packing checks and receiving.

### What information should the first supplier enquiry include?

Send the module model, frame dimensions, roof material or support type, target tilt, panel layout, destination and quantity. Request the proposed kit reference, drawings, installation documents and a quote that lists what the supplier includes.
